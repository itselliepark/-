# 엘리모멘토 편집 가이드 (승인본)

- 승인: 2026-11-09, 테스트 편집본 v4(캐나다 해고 3가지) 기준
- 검토용 페이지: https://claude.ai/artifact/CVf4n38vzjaJADyryFVoF3
- 구현: `remotion/src/elli/ElliEdit.tsx` (스킨 `frost80`), 편집 데이터 예시 `remotion/src/elli/layoff.ts`, 오디오 `scripts/mix_audio.py`

## 1. 형식과 종류
- 1080×1920 세로, 30fps, 45–60초. 1분을 넘기지 않는다.
- 정보성 토킹헤드 릴스. 두 갈래:
  - **경험담 시리즈형**: 다음 편으로 이어짐. 끝은 "다음 편에… Stay tuned".
  - **리스트 팁형**: "○○ 3가지" + TIP n/3 배지. 끝은 "댓글에 '키워드' 남기면 ○○ 보내드릴게요" 또는 "저장해두세요".
- 구성: 훅 0–3초 → 문제·공감 → 본론 → CTA. 첫 문장이 곧 제목(숫자·대상을 콕 집기).

## 2. 릴스 데드존
- 위쪽 15%(약 290px)는 비운다. 제목, TIP 배지, 카드, 라벨은 모두 그 아래부터.
- 오른쪽 아이콘 줄, 하단 캡션 영역도 피한다.

## 3. 컷 · 줌 · 속도
- 숨 쉬는 구간과 말 사이 쉼을 모두 잘라 숏 하나가 0.9–1.3초가 되게 한다.
- 줌: 기본(1.0) · 살짝 당김(1.08) · 펀치인(1.15) 세 단계. 컷 순간에 바로 바꾸고, 천천히 다가가는 줌은 쓰지 않는다.
- 편집점: 원본의 점프컷마다 구도를 바꿔 튀는 느낌을 숨기고, 자막 덩어리 경계에서 숏이 1.2초를 넘기 전에 구도를 바꾼다(같은 단계 연속 금지). 강조 자막(민트·빨강)이 나오는 덩어리는 1.15 펀치인. 목표는 숏 평균 1.0–1.3초, 최대 1.8초.
- 배속은 쓰지 않는다. 쉼을 잘라 초당 약 8음절이 나오게 한다.
- 카드·배지 없이 얼굴과 일반 자막만 나오는 구간은 5초를 넘기지 않는다. 길어지면 설명 카드(말에 맞춰 한 줄씩 등장), 강조 자막, 펀치인 중 두 가지 이상을 넣는다.

## 4. 색
| 이름 | 값 | 쓰임 |
|---|---|---|
| 민트 | `#8BEBFC` | 핵심 키워드·숫자 강조 자막, 제목 2번째 줄 |
| 빨강 | `#F85956` | 부정·경고 강조 자막 |
| 노랑 | `#FBDB73` | 인용 자막, 형광펜 강조 |
| 블루 | `#0161C6` | TIP n/3 배지(85% 반투명), 카드 안 항목명 |
| 화이트 | `#FFFFFF` | 일반 자막, 라벨, 카드(80% 반투명) |

색 보정은 하지 않는다.

## 5. 폰트와 자막
| 역할 | 폰트 | 색 |
|---|---|---|
| 일반 자막·라벨 | Helvetica Regular (한글은 Pretendard Medium으로 대체) | 흰색 |
| 빨강 강조 | 배달의민족 꾸불림체 | 빨강 |
| 하늘색 강조·제목 | 카페24 아네모네 | 민트(제목 1줄은 흰색) |

- 폰트 파일: `bash scripts/fetch-fonts.sh` (재배포 금지라 저장소에는 없음).
- 위치: 높이의 약 64%(1230px), 한 줄. 일반 자막은 덩어리당 6–14자, 1–1.5초.
- 강조 자막: 외곽선 없이 글자 둘레에 어둡고 흐릿한 그림자(`0 2px 10px rgba(0,0,0,.75), 0 0 4px rgba(0,0,0,.6)`). 비중은 전체의 약 40%.
- **숫자·기간·조건**("3개월 넘게 일했으면", "최대 8주치", "통보기간이")은 항상 강조 자막.
- 맥락 라벨: 자막 바로 위 흰 박스 + 검정 글씨 + 이모지(⭐ ⚠️ 👏).
- 제목: 데드존 바로 아래 2줄, 왼쪽부터 써지듯 등장, 외곽선 없이 강조 자막과 같은 그림자, 아래 흰 라벨로 부제.
- 영어 자막: 기본은 넣지 않는다. 엘리가 영상별로 요청할 때만 한국어 아래에 작게.
- 받아쓰기 오류는 반드시 교정(예: 아로이→ROE, eI→EI, 금여→급여, 통보기관→통보기간, 링띵→링크드인).

## 6. 카드 · 그래픽 (프로스트 글래스)
- 모든 카드·용어 타일·TIP 라벨: 흰색 80% 반투명 유리, 배경 블러(28px), 모서리 44px, 위쪽 흰 하이라이트 테두리. 각진 불투명 카드는 쓰지 않는다.
- TIP 배지: 파란 알약(TIP n/3) + 흰 유리 알약 라벨(테두리 없음). 라벨에는 그 팁에서 실제로 확인할 대상을 쓴다(예: "급여 + 통보기간 체크").
- 용어 설명: "용어 정리" 같은 제목 카드는 만들지 않는다. 용어를 말하는 순간 그 용어 타일이 팝업되고, 다음 용어 타일이 옆에 나란히 붙는다.
- 설명 카드: 항목이 말에 맞춰 한 줄씩 나타날 수 있다(`rowTimes`).
- **카드 내용의 정확성**: 카드는 스크립트 문장의 구조를 그대로 따른다(말한 항목과 같은 순서·같은 표현). 스크립트에 없는 관계를 지어내 끼워 맞추지 않는다. 숫자·기준을 덧붙일 때는 공식 자료(정부 사이트 등)에서 확인한 것만 쓰고, 카드 아래에 작은 글씨로 출처와 연도를 적는다. 확인하지 못한 수치는 넣지 않는다.
- 자료 카드(이메일·문서·화면 캡처): 상단 절반. 가능하면 인물을 따내 카드 앞에 겹친다.
- **마지막 CTA 안내 카드(민트 박스)는 넣지 않는다.** CTA는 말과 자막으로만.
- 등장은 컷에 맞춰 짧은 팝업. 화려한 전환은 쓰지 않는다.

## 7. 사운드
- 배경음악은 넣지 않는다(엘리가 업로드 전에 직접 깐다).
- 효과음은 분위기에 맞춰 영상당 6–12개, 목소리보다 작게: 카드·배지 등장=팝, 펀치인=휙, 숫자·결과 공개=띵, 실패·경고=버저, ✓/✕=정답·오답음, 웃긴 장면=코믹.
- 목소리+효과음을 −16 LUFS(true peak −1.5 dB)로 맞춰 넘긴다.

## 8. 작업 흐름
1. 원본을 드라이브 elliemomento 폴더에서 받는다.
2. whisper.cpp(small, ko)로 단어 단위 받아쓰기 → 자막 덩어리·강조·라벨을 편집 데이터(`src/elli/<영상>.ts`)로 작성.
3. Remotion으로 렌더(`--muted`), `scripts/mix_audio.py`로 오디오 믹스, 합친다.
4. 피드백 보드(https://claude.ai/artifact/QzqtACoRjN5Qv9x6duvdgr)에 버전을 올려 코멘트를 받는다.
5. 가이드 규칙에 비춰 점검한 뒤 넘긴다.
